Opening line — memorise word for word

“I start at both ends so the width is maximum. Each step I compute min of the two heights times width, keep a running max, then move the shorter pointer because shrinking width can only win if the new height is strictly taller. That deletes a whole family of pairs, so the scan is linear.”
