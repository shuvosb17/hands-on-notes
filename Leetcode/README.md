# LeetCode notes

Curated **NeetCode / DSA sheet** (same order as GoalTrack) plus a **BD-reported** extras folder.

Study **topics in numbered order**, then problems **inside each topic in numbered order**.

## How to take notes

Each problem folder is a small notes project:

```
01-two-sum/
  README.md
  index.html      ← write-up (open in browser)
  assets/         ← screenshots, diagrams, whiteboard photos
```

Shared look-and-feel lives in [`_shared/`](_shared/).
